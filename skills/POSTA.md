# POSTA · 信箱协作协议 — agent 技能

> 面向第一次接触 Posta 的 CLI agent（opencode / codex / kilo / claude / zcode …）。
> 领取本技能 = 接受按 Posta 协议干活。读完这一份，即可独立开工。

## Posta 是什么（30 秒）

一群 AI agent 与人类监工靠**文件信箱**协作：任务、交付、审核、裁决全部是目录里的包裹。
不读对话、不靠记忆——**盘上有什么就是什么**。你只需要先认识三样东西：

| 概念 | 是什么 |
|---|---|
| 信箱 | 三个目录：`tasks`（派活）/ `reports`（交付与审核）/ `handoffs`（交接） |
| 包裹 | 信箱里的一个任务目录，名字带目标成员后缀，如 `fix-login-opencode/` |
| DIRECTIVE.md | 包裹里的指令书：授权号、允许路径、冻结清单、验收标准——你的唯一任务来源 |

信箱默认在 `$POSTA_HOME/mailboxes/{tasks,reports,handoffs}`（v0.1 旧布局为
`~/cto-tasks` 等）。**路径永远以 DIRECTIVE 给出的为准，不要猜。**

你的身份与后缀查 `$POSTA_HOME/agent/TEAM_ROSTER.json`（团队注册表——成员互相认识的
唯一事实来源）。身份未明就标 unknown 并上报，不许猜。

## 第一步：领包裹

1. 扫 tasks 信箱，找**带你自己后缀**的 DIRECTIVE 包裹。
2. 不是你的不碰；找不到自己的、或对身份有疑问 → 按下文"上报规则"处理。
3. 认领即开工。动工前**通读 DIRECTIVE 全文**：授权号（AUTHORIZATION_ID）、允许路径、
   冻结清单、验收标准、交付位置。有任何一条没读懂，就不要动手。

## 干活纪律

- **PROGRESS.md 边做边记**：在工作区根，做了什么 / 发现了什么 / 改了什么主意，随时落笔。
  它是监工与人看你过程的眼睛，不是装饰。
- **只动 DIRECTIVE 允许的路径**。没列出的文件 = 禁区，一个字节都不改。
- **冻结基线不可改**：DIRECTIVE 标注冻结的文件，看可以，改不行。
- **失败如实记录**：报错输出、放弃的尝试、未完成的项，原样进 PROGRESS 与 REPORT。
  不掩盖、不美化、不"反复重跑刷绿"。
- 分支纪律照 DIRECTIVE 执行（通常：只进工作分支；`main` 不可写；不 force push）。

## 交付格式

交付到 reports 信箱中该任务的 delivery 目录（确切路径以 DIRECTIVE 为准），三件套：

| 文件 | 内容 |
|---|---|
| `REPORT.md` | 做了什么 / 关键决策与理由 / 自测证据（命令+输出）/ 遗留问题 / 范围外建议 |
| `STATUS.json` | 机器可读结论：`"PASS"` 或 `"FAIL"` + 一句话摘要 + 分支与提交号 |
| `MANIFEST.sha256` | 交付物指纹清单（`sha256sum` 输出），供审核方验证未被篡改 |

- 自测证据（命令 + 输出）原样进 delivery，不裁剪不涂改。
- **FAIL 也要完整交付三件套**：失败本身是有效结果，如实上报优于硬造绿。

## 上报规则（不自行变通）

遇到下列任一情况：**写进 STATUS / REPORT 如实上报，然后停止**。不变通、不越权、
不替监工或人做决定：

1. **失败**：自测不过、修不动、环境缺依赖——保留现场证据，交付 FAIL。
2. **资格冲突**：被要求验收 / 审核 / 修复自己（或与自己署名重叠）的产物。
3. **范围外请求**：DIRECTIVE 之外的好想法或额外修改——写进 REPORT 的"建议"小节，
   一律不实现。
4. **指令矛盾或不可执行**：路径不存在、要求互相冲突、缺授权号——停止，把矛盾点
   写清楚，等新指令。

## 全流程一图

    认领（tasks/ 带自己后缀的包裹）
      → 通读 DIRECTIVE → 干活（PROGRESS 随记 · 只动允许路径 · 冻结不碰）
      → 自测留证 → 交付三件套（reports/…/delivery/）→ 等待审核
      ↳ 任一环节 FAIL / 资格冲突 / 越界请求 → 如实上报并停止

## 原则备忘（Posta 设计原则，理解了更好干活）

文件即状态 · 人只出现在裁决点 · 证据不可变 · 弱模型不做判断（路由查表优先） ·
一切动作必留痕。
